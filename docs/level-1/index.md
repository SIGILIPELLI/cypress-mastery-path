# Level 1 · Cypress Fundamentals

Before writing a single test, you need to understand what Cypress actually is — and it's genuinely
different from a browser-automation client talking to a remote driver. This level builds the fundamentals
from the ground up against a real local Express test-target app: installing and configuring Cypress,
querying the real DOM, interacting with real elements, writing real assertions, and understanding
Cypress's defining feature — built-in auto-waiting and retry-ability.

By the end of this level you can write and run a real Cypress test against any real page, understand why
its commands don't execute the instant you call them, and you'll have built a real, working login-flow
test.
